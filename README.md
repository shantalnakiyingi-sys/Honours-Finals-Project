# Nicole Nakiyingi Honours-Finals-Project Repository 2026

## Description of Repository  

The repository consists of the bioinformatics workflow and code(bash scripts) used  throughout the Honours project for Nicole Nakiyingi at Stellenbosch University in 2026. 

## Project title 

Designing Next-Generation African-Derived Lactobacillus crispatus-based Live Biotherapeutics for the Treatment of Bacterial Vaginosis: A Genomics-Guided Approach. 

## Study significance 
Bacterial vaginosis (BV) is a common vaginal condition characterised by alterations in the vaginal microbiome, including a reduction in protective Lactobacillus species and an increase in bacterial diversity.

This project contributes to the development of next-generation live biotherapeutics by investigating the genomic diversity and functional potential of vaginal Lactobacillus crispatus isolates from an African cohort. Identifying promising strains may help inform the development of locally relevant, genomics-guided biotherapeutic approaches for BV.
